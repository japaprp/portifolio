# Estrutura comercial do portfólio

Atualização de 07/09/2026. O site principal foi reorganizado para funcionar como vitrine comercial, sem misturar produto pronto com roadmap.

## As 7 etapas aplicadas

1. **Posicionamento profissional** — abertura focada em desenvolvimento de sistemas para negócios reais, não apenas em tecnologias.
2. **Projetos com contexto** — cada produto passa a explicar o problema, a solução e o nível atual de maturidade.
3. **Separação por maturidade** — publicado, hardening, em desenvolvimento e longo prazo.
4. **Modelo de trabalho** — fluxo explícito: entender, planejar, construir, testar, implantar e evoluir.
5. **Serviços comercializáveis** — sistemas empresariais, PDV/comércio, SaaS multi-tenant e integrações/automações.
6. **CTA comercial** — contato orientado para diagnóstico do negócio, com WhatsApp, GitHub e LinkedIn.
7. **Hierarquia de portfólio** — Hamburgueria/Multi-PDV e Portal RH aparecem como prioridades comerciais; Varejão, Salões, Perifa Pro e LeitorCodigo ficam como produtos em evolução; Estância aparece como case institucional; Infinit War fica explicitamente como projeto de longo prazo.

## Regra de comunicação

O portfólio não deve apresentar funcionalidade planejada como funcionalidade entregue. Um produto só deve receber comunicação de pronto para produção depois que o código passar pelo hardening, testes e validações correspondentes.

## Próxima evolução

Conforme as auditorias forem corrigidas, os status do site devem ser atualizados. O objetivo é que o visitante consiga identificar rapidamente quais produtos podem ser demonstrados, quais estão em preparação para venda e quais ainda são projetos de longo prazo.
